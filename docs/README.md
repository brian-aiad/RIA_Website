# Project documentation

Keep project handoffs and supporting documentation in this folder.

- [October 14 release](RELEASE-2026-10-14.md): latest publication authorization and release limitations.

- [Website handoff](HANDOFF.md): complete client context, implementation history, architecture, route inventory, validation results, release restrictions, and remaining setup. Prepared October 13, 2026.
- [Generated assets](GENERATED_ASSETS.md): existing generated-asset documentation.

For future handoffs, use descriptive dated filenames such as `HANDOFF-YYYY-MM-DD-topic.md` and add a link here. Preserve older handoffs as historical snapshots; identify which document reflects the latest state.

Local screenshots, QA reports, and measurement artifacts remain under the Git-ignored `output/` directory. Share those separately when their evidence is needed. Never include credentials in handoff documents.
